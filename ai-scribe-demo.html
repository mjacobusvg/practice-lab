Where this is, and where it's going

Being straight with you: this is a real tool you can use today, and it is also still being built. Here is exactly what is live now and what is in development, so you know what you are getting.

Live Now

  • Reasoning checkpoint that reads your HPI and prior assessment and surfaces the clinical decisions before it writes
  • Generated assessment as one unified formulation, built from the decisions you confirm
  • Code-ready psychotherapy add-on with all five elements an auditor looks for
  • Talk-it-through mode to reason through a case with it before writing
  • Chart Audit + Coder: consistency check, E/M level the documentation supports, add-on defensibility

In Development

  • HPI generation into your own saved template, not a one-size format imposed on you
  • Plan section assembled from your saved Vault blocks (crisis language, PARQ, return criteria)
  • Ambient capture that pre-fills the structured inputs for you to review

The current version generates the assessment and psychotherapy add-on from an HPI you have already written or dictated. It is not an ambient listener. It is a reasoning-first tool for the sections that carry the most clinical and audit weight, the parts clinicians often still have to edit most heavily. The HPI is held back on purpose: it is the most personal section of the note, so it is being built to fit each clinician individually rather than shipped as one generic generator.
